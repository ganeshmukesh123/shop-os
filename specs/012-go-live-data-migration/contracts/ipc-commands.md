For a new backfill, the operator transcribes the date on the physical bill as `paperBusinessDate` (YYYY-MM-DD). Compare it to the business date, in the shop's `time_zone` setting (FR-019a, default Asia/Kolkata), of the same save timestamp used to post the bill. Refuse a different date with `NOT_SAME_DAY` before posting. Back-fill is same-day only (FR-007): a paper bill from an earlier business date, for example one written before midnight in an outage that ran past it, stays in the paper book and is covered by that day's old-book entry in `reconcile.enter`, because posting it would change a day that is already closed. Ordinary `bills.save` still derives its date at save time.

Practice commands use `training.sqlite`. In training mode, `training.records.save`, `sync.*` and `backup.cloud*` return `TRAINING_MODE`. The training screen directs the trainer to leave training, then enter session results against the live staff list. Live readiness reads those live records.
