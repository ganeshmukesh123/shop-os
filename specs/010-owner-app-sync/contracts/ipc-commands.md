# Contract: desktop commands added by feature 010

Rules as in `specs/001-shop-os-mvp/contracts/ipc-commands.md`, with 005's checks. Every existing writing command now also writes one `sync_outbox` row in its transaction (no change to its input or result).

| Command                                          | Input                                                  | Result                                                                                                                                                                                                 | Error codes                                       |
| ------------------------------------------------ | ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------- |
| `sync.status`                                    | `{}`                                                   | `{ pendingCount, oldestPendingAt?, lastPushAt?, lastPullAt?, level: "ok" or "behind" or "offline" or "revoked", serverSkewMs? }` (the indicator turns amber at "behind": pending older than 5 minutes) |                                                   |
| `sync.now`                                       | `{}`                                                   | `{ pushed, pulled }`                                                                                                                                                                                   | `OFFLINE`, `DEVICE_REVOKED`, `SCHEMA_TOO_OLD`     |
| `sync.rejected`                                  | `{}`                                                   | `{ ops[{ opType, docNo?, code, at }] }` (kept records the server flagged)                                                                                                                              |                                                   |
| `devices.createCode` (owner)                     | `{ kind, counterCode? }`                               | `{ code, expiresAt }`                                                                                                                                                                                  | `OFFLINE`                                         |
| `devices.register`                               | `{ code, label }`                                      | `{ deviceId, counterCode }`                                                                                                                                                                            | `CODE_INVALID`, `OFFLINE`                         |
| `devices.list` / `devices.revoke` (owner)        | `{}` / `{ deviceId, reason }`                          | `{ devices[] }` / `{ atRisk }`                                                                                                                                                                         | `OFFLINE`                                         |
| `restore.fromServer`                             | `{ code }` (fresh install only)                        | `{ restored, throughServerSeq, nextNumbers[] }` (app restarts)                                                                                                                                         | `NO_SNAPSHOT_YET`, `CHECKSUM_MISMATCH`, `OFFLINE` |
| `backup.cloudStatus`                             | `{}`                                                   | `{ lastUploadAt?, lastError? }`                                                                                                                                                                        |                                                   |
| `backup.showRecoveryKey` (owner, once at set-up) | `{}`                                                   | `{ recoveryKey }`                                                                                                                                                                                      | `ALREADY_SHOWN`                                   |
| `conflicts.list` / `conflicts.resolve` (owner)   | `{}` / `{ id, choice: "keep_local" or "take_remote" }` |                                                                                                                                                                                                        |                                                   |
| `approvals.requestRemote`                        | `{ approvalId }`                                       | `{ status }` (waits up to 2 minutes; falls back to PIN)                                                                                                                                                | `OFFLINE`                                         |
