# Contract: commands added or changed by feature 015

Rules as in `specs/001-shop-os-mvp/contracts/ipc-commands.md`, with 005's checks (printer and scanner setup need `settings.edit`).

| Command                            | Input                                                                                | Result                                                                                                | Error codes                                            |
| ---------------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `printers.listOs`                  | `{}`                                                                                 | `{ printers[{ name, displayName, isDefault, status }] }`                                              |                                                        |
| `printers.profiles.list` / `.save` | `{}` / profile fields of `data-model.md`                                             | `{ profiles[] }`                                                                                      | `PRINTER_NOT_FOUND`, `INVALID_WIDTH`                   |
| `printers.testPage`                | `{ profileId }`                                                                      | `{ spooled, includesDevanagari: true }` (the user then answers "Did the Hindi text print correctly?") | `PRINT_FAILED`                                         |
| `printers.recordTestResult`        | `{ profileId, printsDevanagari }`                                                    | `{ profile }`                                                                                         |                                                        |
| `bills.print` (changed)            | `{ id, target? }` (target defaults from the profile for bills)                       | `{ result: "spooled" or "failed" or "cancelled", reason? }`                                           | `PRINT_FAILED` (bill unaffected), `NO_PRINTER_PROFILE` |
| `documents.print`                  | `{ docKind, docId, profileId? }` for returns, quotes, challans, receipts, statements | as above                                                                                              |                                                        |
| `print.log`                        | `{ docKind, docId }`                                                                 | `{ attempts[] }`                                                                                      |                                                        |
| `scanners.profiles.list` / `.save` |                                                                                      | `{ profiles[] }`                                                                                      |                                                        |
| `scanners.recordScan`              | `{ profileId }` (renderer reports a detected burst)                                  | `{ lastScanAt }`                                                                                      |                                                        |
| `labels.print` (changed from 002)  | adds `profileId?` and `kind: "location_tag"` with `locationIds[]`                    | `{ result }`                                                                                          |                                                        |
| `hardware.health`                  | `{}`                                                                                 | `{ checks[{ component, level: "ok" or "warning" or "problem", message, nextStep? }] }`                |                                                        |

The renderer's scan listener calls 002's `items.lookupBarcode` with the normalised code and, if nothing matches, opens the unknown-barcode panel (search, create item, record unmet demand).
