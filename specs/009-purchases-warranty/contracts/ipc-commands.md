# Contract: commands added or changed by feature 009

Rules as in `specs/001-shop-os-mvp/contracts/ipc-commands.md`, with 005's session and permission checks (`stock.receive` for receipts; `price.edit` for accepting suggested prices; `payment.receive` is not enough for payments out, which need a new `payment.pay` permission: Owner and Manager allow).

## Goods receipts

| Command                          | Input                                                                                                                                                                                                                                                                                            | Result                                                                                                                                                         | Error codes                                                                                            |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `receipts.draft.save`            | `{ id?, partyId, supplierInvoiceNo?, supplierInvoiceDate?, locationId, lines[{ itemId, enteredUom?, invoicedQtyMilli, receivedQtyMilli, damagedQtyMilli, unitPricePaise, batchCode?, mrpPaise?, mrpPackQtyMilli?, gstRateBp?, gstPaise?, isiNumber? }], charges[{ kind, amountPaise, basis }] }` | `{ receipt, preview: { lines[{ goodMilli, shortMilli, excessMilli, sharePaise, landedCostPaise, priceRise?, suggestedSellingPaise?, warnings[] }], totals } }` | `NOT_A_DISTRIBUTOR`, `INVALID_QUANTITY` (damaged above received), `UNKNOWN_UNIT`, `INEXACT_CONVERSION` |
| `receipts.post`                  | `{ id, clientReceiptId }`                                                                                                                                                                                                                                                                        | `{ receipt, movements[], batches[], alerts[] }`                                                                                                                | `ALREADY_POSTED`, `EMPTY_RECEIPT`                                                                      |
| `receipts.list` / `receipts.get` | `{ status?, partyId?, from?, to? }` / `{ id }`                                                                                                                                                                                                                                                   | includes "Received, not billed"                                                                                                                                | `NOT_FOUND`                                                                                            |
| `receipts.discardDraft`          | `{ id }`                                                                                                                                                                                                                                                                                         | `{}`                                                                                                                                                           | `ALREADY_POSTED`                                                                                       |

`receipts.post` is one transaction: number, `purchase` movements (good to the location, damaged to Defective) through 007's `MovementService`, batches, price history, compliance records, exceptions (price rise, missing ISI, duplicate invoice), audit entry. Idempotent by `clientReceiptId`.
